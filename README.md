# GIF转换器

浏览器本地视频转 GIF 和 GIF 转 GIF 工具。支持固定画布、拖动与拉伸素材，以及上层 PNG 叠图。素材不会上传到服务器。

[在线应用](https://framegif-studio-m1971.gzzy666666.chatgpt.site) · [GitHub](https://github.com/3289004205/mrk-video-to-gif)

## 使用

1. 选择「视频转 GIF」或「GIF 转 GIF」，选择或拖入相应文件。视频推荐 H.264 MP4 或 WebM；格式支持取决于浏览器。导入 GIF 会自动切换到 GIF 模式。
2. 设置导出画布：原始比例、1:1、4:3、3:4、16:9、9:16，或自定义宽高。每边支持 32–1920 px。导出文件严格采用此宽高，素材可在框内缩放、变形或裁出边界。也可选择透明、白色、黑色背景。
3. 在预览下方选择要编辑的图层，拖动画面移动、拖拽四角缩放，或直接输入 X / Y 位置和宽高（单位为画布像素）。勾选「等比缩放」可保持当前比例；取消后可独立拉伸宽高。「适应画布」完整显示素材，「铺满画布」保持比例覆盖，「拉伸填满」变形至画布宽高。
4. 点击「上传 PNG 叠图」。PNG 始终位于视频 / GIF 上方，可以独立拖动、缩放、拉伸、替换或移除。PNG 透明区域会露出下方动画，PNG 最大支持 1600 万像素。
5. 设置帧率（1–24 FPS），默认转换完整视频或完整 GIF 动画。GIF 模式可选择 256 / 128 / 64 / 32 色。
6. 应用从完整素材采样最多 5 张最终构图画面，包含画布背景、素材变形与 PNG，按相同参数编码并估算体积。改变参数或构图会重新估算；实际大小以完整导出为准。
7. 点击「生成 GIF」预览、下载。按所选参数完整编码，不设目标大小，也不自动降低尺寸、帧率或颜色数。GIF 模式显示原文件与导出文件的大小及增减比例。

转换支持取消。GIF 不含音频；刷新会清除当前素材、叠图和结果。体积小于 1 MB 时显示 KB，使用十进制单位。画布选择变化会将图层重新适配至画布，建议先设置画布，再调整图层。

## 本地运行

在本目录执行 `python -m http.server 8787 --bind 127.0.0.1 --directory dist`，打开 http://127.0.0.1:8787 。需通过 HTTP 使用模块及编码 Worker，不要直接双击 HTML。

`dist/app.js` 管理解码、动画采样、预估与导出。`dist/composition.js` 管理画布、PNG、图层交互及共用的合成绘制方法，使用同一套归一化位置参数驱动预览和导出。`dist/encoder-worker.js` 在 Web Worker 中逐帧量化、编码，控制并发帧内存。

`dist/gif-source.js` 使用 [omggif 1.0.10](https://github.com/deanm/omggif) 解码 GIF，逐帧处理局部帧、透明背景及 disposal 2/3 的画面清理与恢复，不一次性展开全部帧。GIF 源图最多 1600 万像素。许可证见 `dist/vendor/LICENSE-omggif.md`。

编码使用 [gifenc 1.0.3](https://github.com/mattdesl/gifenc)，MIT 许可证见 `dist/vendor/LICENSE-gifenc.md`。GIF 支持最多 256 色与单比特透明；半透明 PNG 在与底图合成后按 GIF 格式编码。已经高度优化的原 GIF 重新编码后也可能变大。

静态文件可部署到常规 HTTP 静态服务器。Sites 身份保存在 `.openai/hosting.json`。
